## 👨‍💻 About Me

I'm a software engineer focused on building web applications, exploring cybersecurity, and developing practical solutions that integrate AI and data-driven technologies.

My interests span the full software lifecycle, from designing user interfaces and developing APIs to deploying applications, securing infrastructure, and monitoring system activity.

- 💻 **Full-Stack Development:** Building responsive web applications, backend services, APIs, and database-driven systems.
- 🔐 **Cybersecurity:** Learning and applying secure coding, access control, vulnerability assessment, Linux hardening, and security monitoring.
- 🤖 **AI/ML & Data Science:** Exploring AI-powered applications, Python-based data processing, and machine learning workflows.
- ☁️ **Infrastructure & DevOps:** Working with Linux, Docker, Nginx, Git, CI/CD, and application deployment.
- 📚 **Continuous Learning:** Strengthening my engineering fundamentals through hands-on projects, experimentation, and structured learning.

I value clean code, practical problem-solving, maintainable architecture, and security throughout the development process.
