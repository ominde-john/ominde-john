## About Me

I'm a software developer focused on building practical, secure, and scalable digital solutions. My work combines web application development, system security, and an interest in applying artificial intelligence to real-world problems.

I developed **NONEAA**, a school management and education platform, and have worked on maintaining its security and reliability.

My approach is to build software that solves genuine problems, delivers a good user experience, and is designed with security and maintainability in mind.

- **Software Engineering:** Web applications, frontend development, backend integration, and database-driven systems.
- **Cybersecurity:** Application security, secure development practices, and system protection.
- **AI & Machine Learning:** Intelligent applications, Python-based development, and AI integration.
- **Problem Solving:** Turning requirements into reliable, practical software.
